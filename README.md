# physics_lab · 高中物理力学虚拟实验室

基于 **box2d-wasm** 物理引擎 + **Canvas** 渲染的高中物理力学模拟器。

- 功能规划文档：[docs/FEATURES.md](docs/FEATURES.md)
- 当前进度：**一、二、三期全部完成**——沙盒 + 26 个预设实验 + 图表/测量/连接件 + 教学闭环（CSV/场景分享/理论曲线/任务卡）

## 快速开始

```bash
npm install
npm run dev        # 开发：http://localhost:5173
npm run build      # 产出 dist/（tsc 类型检查 + vite 构建）
npm run preview    # 预览生产构建
```

> 本机没有全局 Node.js 时，可使用已下载的便携版（加入 PATH 即可）：
> `C:\Users\J\.local\node-v24.21.0-win-x64`
> 项目 `.npmrc` 已配置 npmmirror 镜像源。

## 核心概念

- **双视角**：平面模式（俯视水平面，重力垂直屏幕向内，世界重力为 0）与垂直模式（侧视竖直面，重力沿屏幕向下、大小可调，含月球 1.63 / 失重 0）
- **交互形态**：自由沙盒 + 预设实验库（26 项，按教材知识点分组）
- **教学核心**：力矢量（v/a/G/ΣF/N/f/外力）、频闪轨迹、实时数据面板、图表探针

## 技术栈

Vite + TypeScript + box2d-wasm（Box2D 2.4 WASM）+ Canvas 2D。
固定步长（1/60 s）物理循环 + 累加器；`vite.config.ts` 中将 box2d-wasm 排除出依赖预打包（emscripten glue 需按相对路径加载 .wasm）。

### 引擎适配要点（踩坑记录）

- 枚举值挂在模块顶层（`b2.b2_dynamicBody`），非 `b2.b2BodyType.*`
- `b2PolygonShape.Set` 只接受 WASM 连续内存指针（不能传 JS 数组）：用 `b2._malloc` + `b2.HEAPF32` 逐顶点写入再传入，`Set` 内部拷贝、随后 `_free` 安全（已验证顶点原样存储，仅可能重排起始点）
- 刚体 fixture 链表尾部 `GetNext()` 返回**真值哨兵对象**（非 JS null），遍历不能用真值判断结尾——fixture 数量可由形状确定推出，按数量有界迭代（`bodies.ts` 的 `eachFixture`）
- 接触流形的 `points` 属性只暴露第 1 个接触点，且"视为质点"（固定旋转）时求解器会把冲量任意集中 → N/f 反推采用**力平衡法**（m·Δv/dt 减已知力），对所有情形精确
- embind 的 `CreateJoint` 返回基类包装，铰链马达等派生接口需 `b2.castObject(joint, b2.b2RevoluteJoint)`
- Box2D 摩擦组合为 √(μ₁μ₂)：定量实验中地面 μ 取与物体一致

## 目录结构

```
src/
├── core/          # engine(初始化) / bodies(刚体) / geometry(斜面/圆弧形状几何，物理-渲染-拾取共用) / joints(六种连接件) / contacts(N、f、Q 力平衡反推) / sim(世界/驱动/场/步进/序列化)
├── render/        # camera / grid / shapes(含关节与弹簧锯齿) / vectors / traces / instruments(标尺量角器)
├── measurement/   # charts(图表条) / theory(理论曲线注册表) / export(CSV 与文件下载)
├── scenes/        # schema / sandbox / storage(我的实验) / presets(26 个实验)
├── ui/            # toolbar / controls / properties(属性+数据+秒表) / dialog(含弹簧参数/场景导入弹窗)
└── app/           # state / loop / main(装配+画布交互)
```

规划中的三期内容已全部实现；后续可选方向：任意多边形绘制、更多预设的理论曲线、实验报告生成。

## 一、产品定位与设计原则

### 1.1 定位

面向**高中物理力学教学**的自助式虚拟实验室。服务两类用户：

- **教师**：备课演示、课堂投屏实验、布置探究作业；
- **学生**：自主搭建场景验证猜想、完成定量实验、理解抽象概念。

产品同时提供两种使用方式：

- **自由沙盒**：从工具箱中自由创建物体、连接件、施加力，搭建任意力学场景；
- **预设实验库**：按教材知识点组织的实验模板，一键加载，参数可调，附带观测目标。

### 1.2 设计原则

1. **教学优先**：力矢量、频闪轨迹、实时图表是"第一公民"，任何场景都应能回答"力是什么、能量去哪了、图像长什么样"。
2. **定量可验证**：模拟结果要能和课本公式对得上（允许有数值误差，但需可控、可解释，见第六章）。
3. **米制真实尺度**：世界坐标以米为单位，物体尺寸、速度、加速度都取真实数量级（物块 0.1~1 m、速度 1~20 m/s、g = 9.8 m/s²）。
4. **数据驱动场景**：实验场景用 JSON 描述，与引擎解耦，便于扩充实验库而不改代码。
5. **低门槛**：不搭建也能玩——打开即有实验库；不看书也能懂——关键矢量与数据常显。

## 二、双视角模式

模拟器提供两种观察视角，对应高中力学两大类典型情境。切换视角 = 重建物理世界（弹窗提示；进阶版本支持按模式分别保存场景草稿）。

### 2.1 模式定义

| | 平面模式（俯视水平面） | 垂直模式（侧视立面） |
|---|---|---|
| 视角含义 | 从正上方俯视一张水平桌面 | 从侧面观察一个竖直平面 |
| 世界重力 | **0**（重力垂直屏幕向内，2D 世界中不体现） | 沿屏幕**向下**，默认 9.8 m/s² |
| 重力可调 | 始终为 0（可开启"桌面摩擦"由 μ 体现） | 0~25 m/s²，预设：地球 9.8 / 月球 1.63 / 火星 3.71 / 失重 0 |
| 地面 | 无需地面（物体约束在桌面平面内） | 通常需要地面 / 平台 / 斜面作为支撑 |
| 典型情境 | 惯性、摩擦、碰撞、动量守恒、水平圆周、力的合成 | 落体、抛体、斜面、单摆、弹簧、能量转化、竖直圆周 |

### 2.2 视觉区分

- 两种模式使用不同的默认配色与背景（平面模式：桌面纹理俯视感；垂直模式：天空+地面立面感），防止用户混淆。
- 垂直模式屏幕角落常显**重力矢量箭头**与当前 g 值；平面模式显示"重力 ⊙ 垂直纸面向内"的示意符号。
- 模式切换按钮常驻顶栏，图标 + 文字（"平面 / 俯视"、"垂直 / 侧视"）。

### 2.3 同一知识点的跨模式设计

部分概念刻意安排两种视角对照，强化理解：

- **圆周运动**：平面模式看水平圆周（绳系小球绕中心转），垂直模式看竖直圆周（过最高点临界问题）；
- **牛顿第二定律**：平面模式做 a-F、a-m 控制变量实验，垂直模式做自由落体 a=g 特例；
- **动量守恒**：平面模式做一维碰撞，垂直模式做竖直方向碰撞。

## 三、通用功能模块（沙盒能力）

以下能力在两种视角下通用，是自由沙盒的核心，也是预设实验的底层积木。

### 3.1 运行控制

| 功能 | 说明 |
|---|---|
| 播放 / 暂停 | 暂停时仍可编辑场景、查看数据 |
| 单步 | 每次步进 1/60 s，用于逐帧观察碰撞瞬间 |
| 重置 | 回到场景初始状态（初始状态 = 最近一次编辑确认的快照） |
| 清屏 | 🧹 一键清空画布：所有物体、连接件、轨迹、标尺/量角器测量线与图表数据一并清除（弹确认框防误触，画布已空时仅提示）。**保留**当前视角模式、重力 g 与相机位置/缩放，时间归零并自动暂停，脱离当前预设/我的实验归属，可立即重新搭建；清空后 ↺ 重置保持空白 |
| 时间缩放 | 0.1× / 0.25× / 0.5× / 1× / 2×，慢动作用于观察碰撞、形变过程 |
| 重力调节 | 仅垂直模式有效（见 2.1） |
| 网格与标尺 | 可开关；0.5 m / 1 m 网格，坐标轴与刻度数字 |
| 相机 | 滚轮缩放、空白处拖拽平移、一键回到原点 |

### 3.2 物体工具箱

**基础形状**：

- **质点**（点击放置；物理上为极小圆，默认 1 kg，恒视为质点——只平动不转动，任何缩放下保证可见）
- 矩形（拖拽绘制，可旋转）
- 圆 / 球
- **斜面（直角三角形）**：拖拽包围盒绘制（高左低右，角度可调）；单 fixture 凸多边形；宽/高可改，静态地形与动态物体通用（2026-09-26）
- **圆弧轨道**：创建默认 90°（竖直壁→底部水平出口的滑道），选中后在属性面板改**圆心角（5~360°）**——180°=U 形槽、270°/360°=环形轨道（球在环内滚动），半径/厚度同处可改；可勾选**"有底座（外方内弧）"**：外接矩形填充、内弧凹槽，外侧平直、底面平整，动态物体不会翻滚（大圆心角时内弧缩为孔，方形带圆孔）；有厚度的弧带、凹面朝上，按"圆心+拖拽半径"绘制；物理上由多段拼合（弧带 = 偏移旋转盒子，底座 = 以圆心为极点的径向切片，均约 7.5°/段，段间微重叠防卡缝），静态/动态通用，**弧形动态物体默认刚体（可翻滚），可切回"视为质点"**（2026-09-26）
- 固定地形：水平面（矩形平台）、斜面、圆弧/半圆槽——上述形状在"平台"工具组以固定形态创建，摩擦默认 0.5
- 多边形（点选顶点绘制；凹多边形自动凸分解）——规划中

> 矩形/圆形物体提供 **"视为质点"开关（默认开）**：开启时固定旋转、只平动，运动学按质心处理，对应教材质点模型；关闭后为完整刚体，可翻滚、带转动动力学。

**属性面板**（选中物体后显示）：

| 属性 | 范围 | 说明 |
|---|---|---|
| 形状尺寸 | 半径 ≥ 0.02 m；宽/高 ≥ 0.05 m；弧带外半径 ≥ 0.15 m、厚度 0.04 ~ r−0.08 m、圆心角 5~360° | 手动输入改变物体形状：矩形/圆形/斜面（w、h）/圆弧轨道（外半径 r、厚度 t、圆心角）重建碰撞体真实生效（弧形为多 fixture 整体重建），密度不变、质量按 ρ×面积 自动重算，位置/角度/速度不动；固定地形（平台）同样可改。**质点例外**——只有"显示半径"（≥ 0.01 m），仅改变外观大小（渲染与点击拾取），碰撞半径恒为内部常量（0.06 m）、质量不受影响，↺ 重置/保存/重载后外观保留而物理不变 |
| 密度 ρ / 质量 m | 任意正值，下限钳制 0.01（单位：kg / kg/m²） | 手动输入任一项，二者联动（由面积换算）：输入质量自动反推密度 ρ = m/S，输入密度自动重算质量 m = ρS，另一输入框即时同步显示；输入 0/负值钳制为 0.01，防止动态体失去质量。改形状尺寸则密度不变、质量随面积重算（见上行）。编辑立即生效并写入 ↺ 重置快照（以密度为存储基准，保存/重载后质量不变）。质点形状面积无教学意义，直接编辑质量 |
| 视为质点 | 开/关（默认开） | 固定旋转只平动，碰撞/摩擦不产生转动；矩形/圆形/斜面/圆弧轨道动态物体均可切换 |
| 摩擦系数 μ | 0~1 | 静止地形可单独设置 |
| 弹性系数 e | 0~1 | 0 = 完全不反弹，1 = 完全弹性 |
| 初始位置 (x, y) | 世界坐标（米） | 手动输入精确坐标设置初始位置（与拖拽移动等效），↺ 重置回到该处；质点/刚体/固定地形均可编辑。未播放（暂停/静止）时输入框实时跟随当前坐标——拖拽到哪显示到哪；播放中冻结为释放时刻的值，不随运动变化。**成组物体（小车）编辑任一部件的坐标，整组按同一位移增量平移**，保持部件间相对几何不变 |
| 初速度 v₀ | 大小 + 方向（角度 / 拖拽箭头设定） | |
| 颜色 / 名称 | | 多物体实验中区分 A、B 球等 |

**预设材质库**（一键应用一组参数）：

| 材质 | μ（动/静） | e | 密度 |
|---|---|---|---|
| 冰块 | 0.02 | 0.1 | 0.9 |
| 木块 | 0.35 | 0.4 | 0.6 |
| 橡胶 | 0.8 | 0.85 | 1.2 |
| 钢 | 0.15 | 0.6 | 7.8 |

### 3.3 鼠标交互

- **选择 / 拖动**：选中物体后拖动（运行中通过鼠标关节实现，可"拎着"物体感受力）；静止时直接平移，属性面板的初始位置坐标实时跟随（播放中冻结显示）。**成组物体（小车）视为一个整体**：静止时无论抓住车厢还是车轮，都是整车刚性平移（各部件保持相对姿态，不撕开、不变形）；运行中鼠标关节统一挂在车厢上——拎任何部件拖动的都是整车，不会拽着轮子把车带翻。
- **旋转**：选中后出现旋转手柄，或属性面板直接输入角度。
- **复制 / 删除**：快捷键 + 右键菜单。
- **拖拽绘制**：选中形状工具后在画布拖拽出尺寸，松手即创建。
- **双击查看数据**：弹出该物体的实时数据浮窗。

### 3.4 连接件

| 连接件 | 实现方式 | 教学用途 |
|---|---|---|
| 绳（不可伸长） | 距离关节（刚性约束） | 连接体、圆周运动、滑轮 |
| 轻杆 | 距离关节 + 旋转锁定 | 杆模型（可受压，区别于绳） |
| 弹簧 | 应用层每帧施加 F = −k·Δx（见 6.3） | 胡克定律、弹簧振子、弹性势能 |
| 铰链 | 旋转关节（revolute） | 门、杠杆、支架 |
| 滑轨 | 移动关节（prismatic） | 约束物体沿直线/斜线运动 |
| 滑轮组 | pulley 关节 / 定滑轮（旋转关节+绳） | 连接体、力的放大 |
| 马达转台（进阶） | 旋转关节 + 马达（角速度驱动） | 受迫振动驱动源、圆周运动 |
| 钉 / 固定点 | 旋转关节锚定世界 | 单摆悬挂点、杠杆支点 |

**创建交互**：连接件两击创建（第一击：物体或空白=固定锚；第二击：另一物体或空白）；任一端点击空白处即在**点击位置**设立世界固定锚（世界坐标），命中物体则锚在其重心；其中**弹簧**在第二击后弹出"设置弹簧参数"对话框——

- **原长 L₀ (m)**：选"将两物体现在的距离视为原长（≈ 当前两端距离，默认）"或手动输入正数；
- **弹性系数 k (N/m)**：选"默认（20 N/m）"或手动输入正数；
- 取消/Esc/点遮罩则不创建；创建后仍可在属性面板修改 k 与 L₀。

**属性面板编辑**：选中任一被连接物体，面板列出其关联连接件——弹簧可改劲度 k 与原长 L₀，绳/杆可改长度 L（约束即时同步到引擎）。三种连接件（弹簧/绳/杆）均提供 **"将当前长度视为原长"按钮**：一键把两端锚点的当前距离设为原长/长度（最小 0.05 m）——弹簧弹力立即归零（重新标定零点，适合系统稳定后开始新测量）；绳/杆约束长度即时适应当前间距，不产生跳动；结果写入 ↺ 重置快照。

### 3.5 特殊对象

- **小车**：矩形车厢 + 两轮（旋转关节），轮可施加驱动力矩——牛顿第二定律、动能定理的标准载具。车厢与车轮成组（`meta.group`）：拖拽、修改初始位置时整组平移，删除时整组移除。
- **推进器 / 火箭**：可附着在任意物体上，提供恒定推力（大小方向可调），火箭可选"喷气减质量"模式演示反冲。
- **施力箭头工具**：点击物体放置一个持续力（大小方向可调，运行中实时生效/失效开关）。
- **（进阶）人偶 / 火柴人**：多刚体 + 关节，用于超失重直观感受，三期再评估。

### 3.6 测量与可视化（教学核心）

**矢量显示**（每组独立开关，颜色区分，长度按统一比例尺）：

- 力：重力 G、支持力 N、摩擦力 f、拉力/张力 T、外力 F、合力 ΣF
- 运动：速度 v、加速度 a

**频闪与轨迹**：

- **频闪照片**：每固定时间间隔（默认 0.1 s，可调）在物体位置打一个点，形成"打点计时器 / 频闪照相"效果；
- 轨迹连线（可选渐隐）；
- 理论参考线叠加（如平抛的抛物线虚线，见三期）。

**测量仪器**：

- 屏幕标尺：拖拽两点测距离（米）；
- 量角器：拖拽三 点测角度（度），用于斜面倾角、抛射角；
- 秒表：手动计时，或绑定事件（如"碰撞时自动停止"）。

**传感器与图表**：

- 探针可绑定到任意物体，记录时间序列：x-t / v-t / a-t / F-t / E-t；
- 图表面板位于画布下方或右侧，支持多物体同屏对比（不同颜色对应物体）；
- 实时数据面板（表格）：位置、速度、加速度、质量、动能 Ek、重力势能 Ep、动量 p、连接件力（弹簧弹力 |F| / 绳张力 T / 杆作用力 |F|）、**弹簧当前长度 L**（3 位小数，仅弹簧）、支持力 |N|、摩擦力 |f|、摩擦生热 Q、外力功 W外、摩擦功 Wf。

**数据导出**：CSV（时间序列），供课后用 Excel 处理。

## 四、预设实验库

按教材知识点组织，共 **24 个常规实验 + 1 个进阶实验**。每个实验包含：场景要素（自动搭建了什么）、可调参数（学生能改什么）、观测目标（验证/探究什么结论）。实验以 JSON 场景文件实现（见 5.4）。

### 4.1 运动学（5 个）

#### 实验 1：匀速直线运动（牛顿第一定律 / 惯性）
- **视角**：平面
- **场景**：无摩擦冰面（μ=0.02）上一滑块，给定初速度
- **可调参数**：初速度 v₀、滑块质量
- **观测目标**：x-t 图为倾斜直线；速度矢量大小方向均不变；合力为零——没有力也能一直运动（破除"有力才有运动"前概念）

#### 实验 2：匀变速直线运动
- **视角**：平面
- **场景**：光滑水平面上滑块受恒定水平推力
- **可调参数**：推力 F、质量 m
- **观测目标**：v-t 图为直线，斜率即加速度 a；验证 a = F/m；x-t 图为抛物线；频闪点间距逐段增大

#### 实验 3：自由落体运动
- **视角**：垂直
- **场景**：两个不同质量的球（如 1 kg 与 5 kg）同高同时静止释放；下方地面
- **可调参数**：初始高度 h、两球质量、重力 g（切月球对比）
- **观测目标**：轻重球同时落地，a = g 与质量无关；v-t 图为过原点直线，斜率 = 9.8；h = ½gt²；频闪点等差递增

#### 实验 4：平抛运动
- **视角**：垂直
- **场景**：平台上小球以水平初速度抛出；**同屏对照**：同高同时释放的自由落体参考球、同速无重力的水平匀速参考球
- **可调参数**：水平初速度 v₀、抛出高度 h、g
- **观测目标**：与自由落体球始终同高（竖直分运动 = 自由落体）；与匀速球始终同横坐标（水平分运动 = 匀速）；轨迹为抛物线 y = gx²/2v₀²

#### 实验 5：斜抛运动
- **视角**：垂直
- **场景**：小球以初速度 v₀、抛射角 θ 抛出
- **可调参数**：v₀、θ（15°/30°/45°/60°/75° 一键设置）、g
- **观测目标**：射程随 θ 变化，45° 最大（同 v₀）；轨迹对称；最高点速度不为零（水平分量）；θ 与 90°−θ 射程相同

### 4.2 相互作用与牛顿定律（7 个）

#### 实验 6：弹力与胡克定律
- **视角**：垂直
- **场景**：竖直弹簧上端固定，下端挂钩码；旁边立标尺
- **可调参数**：劲度系数 k、逐个添加砝码（质量 m）、弹簧原长
- **观测目标**：F-x 图为过原点直线，斜率 = k；每次增加 Δm，伸长量等差增加

#### 实验 7：静摩擦与滑动摩擦
- **视角**：平面
- **场景**：水平粗糙面上物块，通过施力箭头施加逐渐增大的水平拉力；力矢量实时显示
- **可调参数**：μ、物块质量、拉力 F（支持"随时间线性增大"模式）
- **观测目标**：F < f_max 前物块静止、摩擦力与拉力等大反向（静摩擦被动变化）；F 超过最大静摩擦后开始滑动；滑动后 f = μN 基本恒定
- **教学精度提示**：Box2D 不区分 μs/μd，见 6.2

#### 实验 8：力的合成与分解
- **视角**：平面
- **场景**：静止物体（或质点标记）上施加两个力 F₁、F₂，实时绘制平行四边形与合力
- **可调参数**：F₁、F₂ 的大小与方向
- **观测目标**：平行四边形定则；两力反向时合力为差；垂直时勾股；合力范围 |F₁−F₂| ≤ F ≤ F₁+F₂；正交分解视图

#### 实验 9：牛顿第二定律（控制变量法）
- **视角**：平面
- **场景**：小车置于水平面，恒定水平拉力（或气垫模式 μ≈0），频闪打点
- **可调参数**：拉力 F（质量固定）、质量 m（拉力固定）、μ
- **观测目标**：m 一定时 a ∝ F（a-F 图直线）；F 一定时 a ∝ 1/m（a-1/m 图直线）；学会控制变量法

#### 实验 10：牛顿第三定律
- **视角**：平面
- **场景**：两球同一直线相向运动发生碰撞；F-t 图同屏显示两球各自所受冲击力
- **可调参数**：两球质量比（1:1、1:3、1:10）、初速度、弹性系数
- **观测目标**：碰撞瞬间两力等大反向（F-t 曲线镜像对称），与质量无关；系统总动量始终守恒

#### 实验 11：超重与失重
- **视角**：垂直
- **场景**：电梯（平台）上的物块，"测力计"显示支持力 N（由接触冲量反推，见 6.2）；电梯加速度按预设曲线变化
- **可调参数**：电梯加速度阶段（向上启动 a>0 / 匀速 / 向上减速 / 向下启动 / 向下减速 / a=g 自由下落）
- **观测目标**：N 与 m(g±a) 的对应关系；超重（向上加速/向下减速）；失重（向下加速/向上减速）；完全失重时 N=0

#### 实验 12：斜面与连接体
- **视角**：垂直
- **场景 A（斜面）**：滑块在倾角 θ 的斜面上滑下
- **场景 B（连接体）**：斜面顶端滑块经绳跨过定滑轮连接悬挂砝码
- **可调参数**：θ（10°~60°）、μ、滑块与砝码质量、g
- **观测目标**：a = g(sinθ − μcosθ)（场景 A）；整体法与隔离法：a = (m₂g − m₁g sinθ)/(m₁+m₂)（场景 B）；θ 增大到 tanθ = μ 时恰好匀速

### 4.3 圆周运动（2 个）

#### 实验 13：水平面内的匀速圆周运动
- **视角**：平面
- **场景**：轻绳一端固定于中心转轴，另一端系小球；绳以恒定角速度 ω 转动
- **可调参数**：角速度 ω（或线速度 v）、半径 r、小球质量
- **观测目标**：向心力 F = mv²/r = mω²r，绳张力实时显示验证；向心加速度 a = v²/r 指向圆心；v 一定时 r 越大 F 越小，ω 一定时 r 越大 F 越大

#### 实验 14：竖直面内的圆周运动
- **视角**：垂直
- **场景**：绳（后可切换为轻杆）系小球在竖直平面内绕固定点做圆周运动
- **可调参数**：最低点初速度、绳/杆切换、摆长、g
- **观测目标**：绳模型过最高点临界速度 v_min = √(gr)（低于则提前脱离做斜抛）；最高/最低点张力差 ΔT = 6mg；杆模型最高点速度可为零

### 4.4 机械能（4 个）

#### 实验 15：动能定理
- **视角**：平面
- **场景**：水平面上滑块受水平恒力推动一段位移后撤力，随后进入粗糙段减速
- **可调参数**：F、位移段长度、μ
- **观测目标**：W合 = ½mv² − ½mv₀²，数据面板实时显示"外力功 / 摩擦功 / 动能变化"三者对账

#### 实验 16：机械能守恒定律
- **视角**：垂直
- **场景**：单摆（或光滑圆弧滑轨上的滑块）从一定高度释放
- **可调参数**：释放高度 / 摆角、质量、摆长
- **观测目标**：Ek + Ep 总量恒定（实时条形图：两根柱子此消彼长）；任意位置 ½mv² = mgh；只有重力做功时守恒；若开 μ 则不守恒（对照）

#### 实验 17：弹性势能与动能转化
- **视角**：垂直（或平面）
- **场景**：水平面上弹簧被压缩 x 后释放，弹出滑块
- **可调参数**：压缩量 x、劲度系数 k、滑块质量
- **观测目标**：½kx² = ½mv²；v ∝ x（线性关系）；v ∝ 1/√m

#### 实验 18：摩擦生热与能量守恒
- **视角**：平面（或垂直斜面版）
- **场景**：滑块以初速度冲上粗糙水平面（或从粗糙斜面滑下）直至停止
- **可调参数**：μ、初速度 v₀、质量
- **观测目标**：Q = μmg·d（d 为滑行距离），全部动能转化为内能；v₀ 翻倍滑行距离翻 4 倍（d ∝ v²）；能量账本：Ek + Ep + Q 守恒

### 4.5 动量（3 个）

#### 实验 19：一维碰撞（三种类型）
- **视角**：平面
- **场景**：光滑水平面上两球对心碰撞（追及或相向）
- **可调参数**：两球质量、两球初速度、弹性系数 e（1.0 弹性 / 0.5 / 0 完全非弹性）、追及/相向预设
- **观测目标**：三种碰撞动量均守恒；弹性碰撞动能也守恒（速度交换特例：等质量弹性正碰）；完全非弹性碰后共速、动能损失最多（损失 ΔEk = ½·m₁m₂/(m₁+m₂)·(v₁−v₂)²）

#### 实验 20：反冲（人船模型 / 火箭）
- **视角**：平面
- **场景 A**：静止冰面上两人互相推开；**场景 B**：火箭喷气推进（可选质量减少）
- **可调参数**：两者质量比、推开时的冲量/推力
- **观测目标**：m₁v₁ + m₂v₂ = 0，速度与质量成反比；人船模型相对位移与质量成反比（x₁/x₂ = m₂/m₁）；火箭持续喷气持续加速

#### 实验 21：动量定理
- **视角**：平面（或垂直，落体触地）
- **场景**：小球以一定速度撞上固定挡板，对比"直接碰撞"与"经过缓冲垫"两种情况；F-t 图显示冲击力曲线
- **可调参数**：初速度、缓冲垫弹性、碰撞时长（改变缓冲材料）
- **观测目标**：F-t 曲线下面积（冲量）相等 = Δp；延长作用时间可显著降低峰值力（安全带/气囊原理）

### 4.6 振动（3 个）

#### 实验 22：弹簧振子（简谐运动）
- **视角**：平面（水平弹簧振子，无重力干扰）
- **场景**：滑块两侧连接弹簧（或单侧），拉开振幅 A 后释放
- **可调参数**：k（可双弹簧并联 k₁+k₂）、质量 m、振幅 A
- **观测目标**：x-t 图为正弦；T = 2π√(m/k) 验证；周期与振幅无关（等时性）；v、a 与 x 的相位关系（v 最大在平衡位置，a 指向平衡位置）

#### 实验 23：单摆
- **视角**：垂直
- **场景**：轻绳悬挂小球，拉开小角度释放；周期自动测量（过最低点检测计时）
- **可调参数**：摆长 L、g（切月球验证）、摆角（5° 内 vs 大角度对比）、质量
- **观测目标**：T = 2π√(L/g)；T 与质量、振幅（小角度）无关；g 切月球后 T 变长；大角度时周期略增大（超出简谐近似，教师可拓展）

#### 实验 24：受迫振动与共振
- **视角**：垂直
- **场景**：弹簧振子上端由马达驱动做简谐驱动，驱动力频率 f驱 可调；振子振幅实时测量
- **可调参数**：驱动力频率（扫频模式：自动从 0.2f₀ 扫到 2f₀）、系统 k、m（改变固有频率 f₀）、阻尼（可加）
- **观测目标**：振幅-频率响应曲线，f驱 = f₀ 时振幅最大（共振）；阻尼增大共振峰变平缓；受迫振动频率 = 驱动频率（与自身固有频率无关）

### 4.7 进阶（1 个，可选）

#### 实验 25：万有引力与卫星轨道
- **视角**：垂直（无地面，中央引力源）
- **场景**：中央"行星"（固定），四周可发射"卫星"，引力按 F = GMm/r² 施加（应用层自定义力，非 Box2D 内建重力）
- **可调参数**：发射位置、发射速度大小与方向、GM
- **观测目标**：不同速度对应圆轨道 / 椭圆轨道 / 逃逸；开普勒第二定律（近快远慢，面积速率恒定示意）；第一宇宙速度概念

### 5.3 主循环与时间

- **固定步长**：物理步进 dt = 1/60 s，速度迭代 8、位置迭代 3；
- **累加器模式**：每帧累计 `elapsed × timeScale`，按固定 dt 步进（设子步上限防止卡顿螺旋）；
- **插值渲染**：保存上一步与当前步的变换，按剩余比例插值，慢动作下依旧平滑；
- **单步**：步进一个 dt 后暂停；
- Box2D 数值稳定性：物体尺寸控制在 0.05~10 m、速度 < 30 m/s；高中典型量级天然满足。

## 六、Box2D 能力边界与教学精度要点

Box2D 是游戏级 2D 刚体引擎，教学化使用必须清楚它"不精确提供什么"。以下为专项设计，确保实验结论与课本公式对得上。

### 6.1 引擎直接提供的

刚体动力学、碰撞检测、铰链/滑轮等约束关节、鼠标拖拽关节、碰撞回调、每步接触冲量（normal/tangent impulse）。

### 6.2 需要应用层推导/补丁的量

| 教学量 | 问题 | 方案 |
|---|---|---|
| **支持力 N** | 引擎不直接输出约束力 | 每步汇总物体所受 `normalImpulse ÷ dt` 得 N，用于超失重实验的"测力计示数" |
| **摩擦力 f** | 同上，且求解器摩擦为近似 | `tangentImpulse ÷ dt` 反推；演示 f = μN 时控制物体匀速滑动读数验证 |
| **静/动摩擦区分 (μs vs μd)** | Box2D 只有一个 μ，静摩擦由求解器隐式处理 | 界面上只标"摩擦系数 μ"；实验 7 的"最大静摩擦略大于滑动摩擦"改为教师讲解 + 引擎补偿选项（二期评估：静止判定阈值内人为提高 μ） |
| **摩擦生热 Q** | 引擎无能量统计 | 按 `Q += f · Δs_相对` 累加（由切向冲量 × 相对滑移积分），能量账本由应用层对账 |
| **动能/势能/动量** | 同上 | 应用层按 m、v、y=g 高度直接计算，展示永远用应用层数值 |

### 6.3 自定义力的实现（forces.ts）

- **弹簧**：不依赖关节柔性，每帧 `ApplyForce(F = −k·Δx − c·v_相对)`，好处是 F 值可直接读出用于显示与 F-x 图（胡克定律实验的关键）；
- **空气阻力**：可开关，模型 F = −b·v 或 F = −½ρC_dAv²（落体/抛体实验默认关闭，保证与课本理想模型一致）；
- **中心引力（实验 25）**：F = GMm/r²，按刚体对逐一施加，替代世界重力；
- **推进器**：恒力 + 可选质量流率（火箭反冲）。

### 6.4 已知数值误差与控制

- **摩擦/恢复系数为组合值**：两物体间 μ 取 `sqrt(μ₁μ₂)`（Box2D 规则）、e 取 `max(e₁,e₂)`——教学时把地形设为"中性材质"（μ=μ_m、e=e_m），让物体材质主导，误差可控；
- **碰撞恢复并非理想弹性**：e=1 时仍有微小能量误差，动能守恒验证中标注"误差 < 2%"的期望值；
- **穿透与高速物体**：尺寸/速度限定在 5.3 节范围内即可避免；碰撞实验开启连续物理（bullets）；
- **求解器抖动**：堆叠/静置物体可能有微小抖动，影响"静止物体受力平衡"演示——启用睡眠（sleep）并将速度阈值调低。

### 6.5 明确不做（超出 2D 刚体引擎能力）

- 机械波（横波/纵波、干涉衍射）——需要波动求解器，非本项目范围；
- 流体、连续介质形变；
- 三维场景。

### 二期：测量系统 + 连接件 + 实验库补全（已完成 2026-09-25）

- 传感器与图表：x / y / vx / vy / |v| / |a| / Ek / Ep / |N| 九种曲线、多物体对比（底部图表条，可收起）

- 连接件：绳（距离关节 maxLength，可松弛）、杆（刚性）、弹簧（应用层胡克力 F=kx+c·v，力值可读）、铰链（旋转关节+马达）、滑轨（移动关节）、滑轮（pulley 关节）——两击创建（物体或空白=固定锚）

- 驱动器（运动学脚本）：电梯 a–t 分段脚本、受迫振动简谐驱动（振幅/频率运行时可调）
- 力场：中心引力 F=GMm/r²（卫星轨道实验，圆轨道 r、v 验证精确）
- 实验库扩充至全部 **26 项**（24 常规 + 12 拆斜面/连接体两项 + 卫星进阶）
- 实现要点：涉及"水平面正压力"的实验（静摩擦、牛二、动能定理、摩擦生热、反冲、动量定理）按**教材侧视图**放在垂直模式实现（N=mg 物理严格）；Box2D 摩擦组合规则为 √(μ₁μ₂)，场景中地面 μ 取与物体一致；embind 关节需 `castObject` 取派生接口（马达）
- 补充（2026-09-26）：顶栏运行组新增 🧹 **一键清屏**——确认后清空全部物体/连接件/轨迹/测量/图表数据，保留视角、重力与相机，便于快速重新搭建（见 3.1）
- 补充（2026-09-26）：**弹簧创建参数弹窗**——两击创建弹簧时先询问原长与弹性系数：原长默认"将两物体现在的距离视为原长"（取弹窗打开瞬间的距离快照，最小 0.05 m）或手动输入，k 默认 20 N/m 或手动输入；取消则不创建（见 3.4）
- 补充（2026-09-26）：**连接件"将当前长度视为原长"按钮 + 弹簧当前长度读数**——属性面板中弹簧/绳/杆三种连接件均可一键把两端当前距离设为原长/长度（弹簧弹力归零重新标定零点，绳/杆约束即时同步不跳动，写入重置快照，见 3.4）；实时数据面板新增"弹簧当前长度 L"实时读数（3 位小数，仅弹簧，见 3.6）
- 补充（2026-09-26）：**修复绳/杆长度修改不生效**——box2d-wasm 的 `CreateJoint` 返回基类包装，`SetMinLength/SetMaxLength` 是 `b2DistanceJoint` 派生方法，直接调用会抛异常导致"将当前长度视为原长"按钮点击后长度显示不更新、属性面板手输长度也不同步引擎约束；现经 `b2.castObject` 取派生接口并缓存（`joints.ts` 新增 `distJointOf`，沿用铰链马达 revJoint 的模式），按钮与输入框两条路径均已修复
- 补充（2026-09-26）：**修复连接件第二击空白的锚点错位**——两击创建时第二击落在空白处，固定锚此前误落在世界原点 (0, 0)，现锚定在**实际点击位置**（第一击空白原本就正确）；这同时消除了弹簧创建弹窗"将两物体现在的距离视为原长"与实际锚点距离不符导致的初始弹力突变（现创建即平衡，见 3.4）
- 补充（2026-09-26）：**小车整体移动**——小车（车厢+两轮，`meta.group` 成组）在所有移动路径上视为一个整体：①静止/暂停拖拽无论抓车厢还是车轮，按下时为每个组成员记录抓取偏移，移动时整组刚性平移（保持各部件角度与相对几何，之前拖车厢轮子会留在原地）；②运行中拖拽鼠标关节统一挂到车厢（组内带 `drive` 的成员），拎任何部件都是拖整车；③属性面板"初始位置 x/y"编辑同样整组按位移增量平移。成组删除、序列化/撤销不受影响（见 3.3 / 3.5）
- 补充（2026-09-26）：**斜面与圆弧轨道形状**（`core/geometry.ts` 统一几何源）——物体/平台两组工具各新增三种形状：斜面（直角三角形，`b2PolygonShape.Set` 指针写入顶点，w/h 可改）、四分之一圆弧滑道（竖直壁→水平出口）与半圆 U 形槽（弧带 = 多段 `SetAsBox` 偏移盒子，¼ 圆 12 段/半圆 24 段微重叠防卡缝，r/t 可改）；凹面朝上供小球沿弧滚动（圆周运动/能量守恒）；质量按 ρ×面积 联动（弧带按环形面积，实测偏大约 5% 为段重叠设计量）；序列化/属性面板（含多 fixture 的 μ/e/密度逐个应用）自动支持（见 3.2）。附带踩坑：fixture 链表尾部 `GetNext()` 返回真值哨兵而非 JS null，遍历须按形状推知的数量有界迭代
- 补充（2026-09-26）：**圆弧工具合并 + 圆心角可选 + 弧形物体默认刚体**——"圆弧/半圆"两个工具合并为单一圆弧工具（物体/平台各一），选中时工具箱内嵌"圆心角"选项面板（预置 90°/180°/270°/360° 按钮 + 自定义数字输入 5~360°，默认 90°，`uiState.arcSpan`），拖拽预览实时跟随；`shape.span` 类型放宽为 number（360°=圆环轨道，球在环内滚动、环物体可像轮子滚动），属性面板新增圆心角编辑（重建 fixtures）；弧形**动态物体默认 asPoint=false（刚体，可翻滚/摆动）**，"视为质点"开关可切回；旧场景（span 90/180）自然兼容（见 3.2）
- 补充（2026-09-26）：**圆心角编辑收归属性面板 + 有底座模式 + 工具箱彩色折叠分组**——①撤销工具箱内嵌的圆心角选项面板，创建恒为 90°，圆心角只在选中物体的属性面板修改（`uiState.arcSpan` 移除）；②弧形新增 `base` 标志与属性面板"有底座（外方内弧）"勾选：外接矩形填充、内弧凹槽（>180° 时内弧缩为孔，方形带圆孔），fixture 用以圆心为极点的径向切片拼合（域内从内半径切到矩形边缘、域外从圆心补齐角部，角点方向精确分割保证凸性），实测质量与理论面积一致（180° 底座 2.053 vs 2.046 kg），动态底座槽 5 s 倾角 <0.1° 稳不倒；③左侧工具箱重组为 5 个彩色分组（物体蓝/平台灰/连接橙/对象紫/测量绿），点击组名折叠/展开并 localStorage 记忆，选择与删除常驻首尾（见 3.2 / 3.7）
